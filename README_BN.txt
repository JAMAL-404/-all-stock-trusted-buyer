ALL STOCK 🇧🇩 — TRUSTED BUYER website

FILES
- index.html: website content
- style.css: design and mobile responsive layout
- script.js: mobile menu and current year

BEFORE PUBLISHING
1. Open index.html in a text editor.
2. Replace every occurrence of YOUR_TELEGRAM_USERNAME with your Telegram username (without @).
   Example: if your Telegram username is @allstockbd, use allstockbd.
3. Save the file.

PUBLISH ON GITHUB PAGES
1. Sign in at https://github.com/
2. Click + (top right) > New repository.
3. Repository name: all-stock-trusted-buyer
4. Choose Public, then Create repository.
5. Click Add file > Upload files.
6. Upload index.html, style.css, and script.js (upload the files themselves, not only the ZIP).
7. Click Commit changes.
8. Open Settings > Pages.
9. Under Build and deployment, choose Deploy from a branch.
10. Branch: main; folder: /(root); click Save.
11. Wait a few minutes, then refresh Settings > Pages. GitHub will show the published website URL.

NOTES
- This is a static website; it does not have a database, customer login, or online payment.
- Never collect or sell passwords, one-time codes, or other people's accounts. Use platform-compliant setup/support services.
- Google Fonts is optional; if unavailable, the site uses fallback fonts.
